# Stillroom — private file vault

A personal Node.js and Express file library with a dark glass interface, floating archive animations, quick PDF previews, and one-click Drive shortcuts.

## Run locally

Requirements: Node.js 20 or later.

```powershell
npm install
Copy-Item .env.example .env
```

Set `VAULT_USERNAME`, `VAULT_PASSWORD`, and a long random `SESSION_SECRET` in `.env`, then run:

```powershell
npm start
```

Open <http://localhost:3000>. Files and metadata are stored locally under `storage/`.

## Deploy on Netlify

1. Push this project to a private Git repository and import it into Netlify.
2. In Netlify, add these environment variables with the **Functions** scope and mark credentials as secret values:
   - `VAULT_USERNAME`
   - `VAULT_PASSWORD`
   - `SESSION_SECRET` — generate a long, random value for production.
   - `NETLIFY_BLOBS_REGION=ap-southeast-1` (Singapore; keep the same region for all vault data).
3. Deploy the site. `netlify.toml` publishes the static assets and routes app pages through the private Express function.

Netlify Blobs stores uploaded documents and the vault index persistently across deploys. Blobs are encrypted in transit and at rest; the app only serves them through signed-in routes. Netlify functions cap buffered requests at 6 MB, and binary uploads use about 30% more payload space, so this site limits Netlify uploads to 4 MB. Local uploads remain capped at 100 MB. [Netlify Blobs](https://docs.netlify.com/build/data-and-storage/netlify-blobs/) · [Function limits](https://docs.netlify.com/build/functions/configuration/)

Files already stored in a local `storage/` folder are not copied to Netlify automatically. Export and upload them after the site is deployed if you want them in the hosted vault.

## Security notes

- The dashboard, file previews, downloads, uploads, and link changes require the username and password.
- Keep `.env` out of Git. Configure production credentials in Netlify environment variables, never in `netlify.toml` or the frontend.
- The app uses a signed, HttpOnly, SameSite cookie with an eight-hour expiry and CSRF tokens for form actions. Netlify Blobs keys are generated by the server; requests cannot supply arbitrary storage keys.
- Use a unique, long production password and session secret. The local example password is for development only.
